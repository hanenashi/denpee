# Denpee 🧾

A simple, web-based Japanese receipt (領収証 - *Ryoshusho*) generator and calculator.

**🔗 Live Demo:** [https://hanenashi.github.io/denpee/](https://hanenashi.github.io/denpee/)

### Features
* **Auto-Calculation:** Instantly breaks down totals into **10%** (Eat-in) and **8%** (Takeout) tax categories.
* **Smart Layout:** Automatically zooms to fill 95% of your screen width (great for mobile & desktop).
* **Print Ready:** Hides all buttons and inputs when printing (`Cmd+P` / `Ctrl+P`).
* **Customizable:** Hardcoded Registration Number (T2810881971678) included.

### How to use
1.  Open the [Live Link](https://hanenashi.github.io/denpee/).
2.  Enter the **10% Total** and **8% Total** in the top bar.
3.  The receipt fills itself (including the big total amount).
4.  Type the customer name (`様`) and memo (`但`).
5.  Print to PDF or paper.
